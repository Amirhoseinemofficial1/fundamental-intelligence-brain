# Learning and Review

The controlled loop is outcome → versioned dataset → chronological validation → calibrated Shadow artifact → unseen predictions → real outcomes → Champion comparison → promote/reject → persisted runtime artifact.

Daily research resolves signal outcomes and Shadows, updates source reliability, performs failure attribution and missed-opportunity review, classifies post-exit behavior, evaluates drift, trains eligible specialist/Meta/Entry/Exit challengers, and updates hypotheses/knowledge. Evidence levels require increasing samples, confidence intervals, temporal stability and effect-size gates: hypothesis, weak, moderate, strong, production validated. LLM semantics may assist extraction/research but cannot promote models or stop the deterministic brain.

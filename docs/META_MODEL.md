# Meta Model

The Meta Champion controls final directional probability. Inputs include specialist probabilities, uncertainty, historical Brier evidence, data/source quality, event importance, priced-in and analogue context, volatility/liquidity, cross-assets and learned asset-profile values. Champion replacement is behavior-tested.

LIVE requires accumulated 24h observation plus 24h shadow runtime, minimum event/response/calibration gates, no drift, a promoted Meta Champion, a configurable minimum specialist-Champion count, and an unseen-runtime Shadow improvement record for Meta. Merely setting `signals_enabled=1` cannot bypass this gate.
